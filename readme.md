# 3D Model Analyzer for Game Development

A powerful tool that analyzes 3D models and provides optimization suggestions for game development using machine learning and real-time visualization.

![Project Banner](https://huggingface.co/front/assets/huggingface_logo.svg)

## 🚀 Features

- **Comprehensive Model Analysis**
  - Topology verification
  - UV mapping assessment
  - Polygon density evaluation
  - Mesh quality checks
  - Game-readiness scoring

- **Interactive 3D Visualization**
  - Real-time model viewing
  - Problem area highlighting
  - Non-manifold edge detection
  - High-density region identification

- **Smart Optimization Suggestions**
  - Performance optimization tips
  - UV mapping improvements
  - Topology refinement advice
  - Game-engine compatibility recommendations

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/3d-model-analyzer.git
cd 3d-model-analyzer
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## 💻 Usage

1. Start the application:
```bash
streamlit run 3d_analyzer.py
```

2. Open your web browser and navigate to the provided local URL (typically `http://localhost:8501`)

3. Upload your 3D model file (supported formats: .obj, .stl, .ply, .glb, .fbx)

4. Review the analysis results and optimization suggestions

## 🎮 Interactive Controls

- **Model Rotation**: Click and drag
- **Zoom**: Scroll or pinch
- **Pan**: Right-click and drag
- **Reset View**: Double-click
- **Issue Details**: Hover over highlighted markers

## 📊 Analysis Metrics

- **Game Readiness Score**: Overall quality assessment (0-100%)
- **Topology Analysis**:
  - Vertex count
  - Face count
  - Watertight mesh verification
  - Part count
  - Polygon density
- **UV Analysis**:
  - UV coverage
  - Overlapping UV detection
  - UV space utilization

## 🤖 Machine Learning Features

- Neural network-based quality prediction
- Feature extraction from 3D meshes
- Automated optimization suggestions
- Real-time analysis
